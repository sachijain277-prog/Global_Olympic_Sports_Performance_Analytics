# End-to-end demonstration script (3–5 minutes)

1. **Problem (20 sec):** “This project explores how Olympic medal outcomes vary by country, sport, region and year.”
2. **Data (40 sec):** Open the CSV files and explain athlete-event rows versus aggregate medal results. Explicitly state whether the version being demonstrated uses synthetic demo data or verified official data.
3. **Preparation (30 sec):** Run `python src/data_prep.py`; explain duplicate removal, type conversion and required columns.
4. **Analytics (45 sec):** Open `src/analytics.py`; explain medal trend, sport medal rate and region efficiency.
5. **Web app (60 sec):** Run `python app.py`; show KPI cards, four charts, investment table, and the Tableau integration page.
6. **Tableau (60 sec):** Show the three dashboards and story; demonstrate season, year, country and sport filters.
7. **Testing and limitations (30 sec):** Open the test output and explain why investment efficiency is descriptive, not proof of causation.
8. **Close (15 sec):** Explain what you would improve with more complete official data.
