# Project report template

## Title
Global Olympic Sports Performance Analytics using Python, Tableau and Flask

## 1. Abstract
Write 150–200 words explaining the question, tools, data source, main methods and limits. Do not report demo-data patterns as real Olympic findings.

## 2. Problem statement
Olympic performance is multidimensional. A useful analytics workflow should compare medal outcomes, participation, sport categories and regional differences while keeping Summer and Winter editions distinct.

## 3. Objectives
- Prepare and validate structured sports data.
- Compare medal entries across Games, countries, regions and sports.
- Define transparent sport and region efficiency metrics.
- Explore investment-efficiency relationships without claiming causation.
- Communicate results using Tableau and a Flask interface.

## 4. Tools
Python, Pandas, NumPy, Flask, HTML/CSS, Chart.js, Tableau Public/Desktop, CSV.

## 5. Methodology
Data acquisition → data quality checks → transformation → exploratory analysis → metric definition → Tableau dashboards/story → Flask integration → testing → documentation.

## 6. Dashboard design
1. Olympic Performance Overview: KPI cards, medal trend, top countries, sport rate, season/country filters.
2. Investment and Regional Efficiency: investment vs medal bubble plot, medal efficiency by region, tooltip definitions.
3. Olympic Story: changes over time, host edition comparisons, region/sport mix, annotation of important limitations.

## 7. Results
Add only findings reproduced from the validated final dataset. Include exact filter selections, metric definitions and chart screenshots.

## 8. Testing
Record Python version, setup, data row counts, missing-value checks, route tests, filter checks and screenshots.

## 9. Limitations
Discuss source coverage, medal-counting method, country-code history, investment comparability and non-causal interpretation.

## 10. Conclusion and future scope
Summarize evidence, avoid unsupported claims, and propose more complete official data, inflation-adjusted investment, athlete population/qualification controls and additional filters.
