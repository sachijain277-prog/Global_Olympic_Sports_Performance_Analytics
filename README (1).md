# Global Olympic Sports Performance Analytics

**A custom student project combining Python, Pandas, Tableau and Flask.**

> Data integrity note: The included CSV files are **synthetic demonstration data** generated for this project. They are not official Olympic records and the investment amounts are fictional. The application and analysis code are real, but findings from demo data must not be presented as historical facts. Replace the demo files with licensed/verified datasets before making factual claims.

## Project goals
- Explore medal outcomes and participation by year, country, region and sport.
- Compare medal entries per athlete-event entry across sports.
- Explore a carefully labelled investment-efficiency metric.
- Create Tableau dashboards and a story.
- Present the analysis through a responsive Flask web interface.

## Run locally (Windows)
1. Install Python 3.10 or later.
2. Extract this ZIP and open the folder in VS Code.
3. Open Terminal in the project folder.
4. Create an environment:
   ```powershell
   py -m venv .venv
   .venv\Scripts\activate
   ```
5. Install dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
6. Prepare the data:
   ```powershell
   python src/data_prep.py
   ```
7. Start the web app:
   ```powershell
   python app.py
   ```
8. Open `http://127.0.0.1:5000` in your browser.

If `py` is not recognized, try `python` instead. To stop Flask, press Ctrl+C in the terminal.

## Main analysis metrics
- **Medal entries:** athlete-event rows with Gold, Silver or Bronze.
- **Sport medal rate:** medal-winning athlete-event entries divided by all athlete-event entries in that sport. This is not an official medal table and can differ from medals per unique athlete.
- **Regional medal efficiency:** medal-winning athlete-event entries divided by all athlete-event entries for a region.
- **Medals per USD million:** medal entries divided by the demo investment amount for the same country/year/season. This is illustrative, not causal evidence.

## Replacing demo data
Read `docs/DATA_SOURCES_AND_LIMITATIONS.md` before replacing data. Keep the required column names or update `src/data_prep.py` and `src/analytics.py`. Do not mix Summer and Winter editions without retaining the `season` field.
